CrashDefNet

Learned deformation prediction for crash simulations

My most extensive private project, built from scratch and informed by my experience with deep learning for crash simulation. CrashDefNet learns from finite element simulations and predicts, step by step on the simulation mesh, how a structure deforms and which stress it carries.

It covers the full workflow from raw simulation data to validated predictions, and stays lean enough that new model architectures can be added and compared quickly. The goal: a simple, flexible base for testing new models, shared with the community.

v0.2.0 · 2026MeshGraphNets & MGN-TransformerPyTorch Geometric

CSVProfessional · IDIADA

Crash test signal validation

Automatic OK/NOK check of crash test sensor signals

A neural network that flags faulty sensor signals from crash tests. It combines an image model of the signal curve with computed signal characteristics such as peaks, energy and frequency content. Evaluated with stratified cross-validation and confidence intervals.

PyTorchResNetSciPy
CPPProfessional · IDIADA

Crash pulse prediction

A full acceleration curve from four scenario parameters

From impact position, impact angle and the speeds of both vehicles, the model predicts the complete acceleration curve over time. I compared several network types, from simple baselines to convolutional and recurrent models, after first checking that the relationship is non-linear enough to justify deep learning.

KerasPyTorchXGBoost
IMGProfessional · IDIADA

Object detection pipeline

Image recognition of technical equipment, end to end

A complete computer vision pipeline: collecting images, labelling them automatically with a first model, removing near-duplicates, training a YOLO detector locally or on AWS SageMaker, and serving it as a serverless AWS Lambda prototype with a small desktop and web front end.

YOLOAWSDockerFlask
LLMProfessional · IDIADA

LLM automation toolbox

LLM-based analysis of code and slides, automated

A small internal Streamlit app that prepares source code or PowerPoint files, passes them to an LLM through browser automation and returns the result as a readable HTML report. Clearly layered, with basic safeguards for file handling and access.

LPBF
Research · TC NeustadtPeer-reviewed · Materialia 2023

Distortion of 3D-printed metal stents

Finite element simulation of laser powder bed fusion (L-PBF)

A validated thermo-mechanical simulation of 3D-printed stent lattices. It shows how strut angle, strut thickness and transition radius drive the distortion, and how pre-compensating the geometry brings the printed part close to its target shape. The engineering basis my data science work builds on.

FEMThermo-mechanicsAdditive manufacturing
