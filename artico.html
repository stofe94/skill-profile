arTIco

A framework for classifying multichannel time series, developed in the research project arTIco (Artificial Intelligence and Correlations).

View on GitHub ↗ Original repository ↗

The research project

arTIco started in January 2022 as a two-year research project on validating digital twins with artificial intelligence. In vehicle safety, virtual models are usually checked against a few sensors and fixed tolerance corridors, which captures the real physics only partly.

The project's idea: preserve the knowledge of experienced engineers and combine it with machine learning, so that the quality of a virtual model can be judged more broadly and more objectively. The application example was crash test dummy models in passive vehicle safety. The long-term aim is more confidence in crash simulations, so they can replace more of the expensive hardware tests.

arTIco was funded by the Free State of Bavaria in the Bavarian Cooperative Research Programme (BayVFP), funding line Digitalization.

My part

I worked on arTIco at IDIADA together with Franz Plaschkies from Technische Hochschule Ingolstadt and my IDIADA colleague Zhengxuan Yuan. The framework is one of the first complete tools I was able to publish after switching into data science, and it was my entry into more demanding data science problems around crash simulation and CAE.

What the framework does

  • One standard pipeline. Load the data, train, evaluate. Each run is controlled by a single parameter file.
  • Several time-series models. Convolutional and recurrent networks for time series (1D-CNN, LSTM-FCN, InceptionTime) behind a common interface. New models go into one folder.
  • Automatic tuning. Hyperparameter search with Optuna.
  • Solid evaluation. Stratified cross-validation with confidence intervals and metrics that stay fair when classes are unbalanced.
  • Reproducible experiments. Every run stores its parameters, results, trained pipeline and log.

The public version works with generated dummy data in the same format as the project data: simulation signals, expert ratings and objective ratings according to ISO 18571.
