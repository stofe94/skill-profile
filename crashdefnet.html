CrashDefNet

Learned deformation prediction for crash simulations. A lean PyTorch workflow from simulation data to predictions, built so that new model architectures can be tried out quickly.

View on GitHub ↗

What it does

CrashDefNet (Crash Deformation Network) learns from finite element simulations. It treats the simulation mesh as a graph and predicts, one time step after another, how the mesh deforms and which stress it carries. Chaining these steps reproduces the deformation of a whole part.

Learned models like this aim to give engineers deformation results much faster than a full crash simulation. CrashDefNet provides the workflow around such models and keeps it small and readable, so different architectures can be compared under the same conditions.

How it works

  1. 1Simulation dataFE results exported to a dataset
  2. 2Mesh as graphnodes, element edges and contact
  3. 3Graph networkpredicts the next time step
  4. 4Rolloutstep 3 repeated over time
  5. 5Evaluationmetrics, reports, ParaView

A new architecture replaces step 3. Everything else stays the same, which keeps comparisons fair.

Background

CrashDefNet builds on the experience I gained working on deep learning for crash simulation, a topic I worked on intensively at IDIADA.

About a year ago I started CrashDefNet as a private project and built it from scratch: a lean tool of my own for trying out ideas and running small tests quickly and flexibly. It has grown steadily since. Today its main purpose is to test new model architectures soon after they are published, and to make this simple, flexible base available to others.

What's included

  • Two graph network architectures in one pipeline: MeshGraphNets and the recent MeshGraphNet-Transformer.
  • Easy to extend. A new architecture needs little code; data, training and evaluation stay unchanged.
  • Fair comparison. Every model uses the same data, training loop and metrics.
  • Traceable results that can be viewed in ParaView.
  • From laptop to GPU. Quick tests run on a CPU, larger runs on a GPU via Docker.

Status

Version 0.2.0 is the first public release. It is developed on DeepMind's public deforming_plate dataset, a simplified crash case with contact and large deformation. First training runs show that the whole chain works end to end. The results so far are preliminary; setup, figures and their limits are documented in the repository.

Next steps

  • Add and test further recent architectures as they are published.
  • More complex crash scenarios with dynamic impact and plasticity.
  • Work directly with data exported from CAE solvers.
